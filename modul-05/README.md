## 1. Problem Statement
> Membuat dan mengimplementasikan program komputasi untuk mengurutkan data acak berupa 100 nilai ujian siswa. Menyusun sekumpulan data dari nilai terkecl ke nilai terbesar (ascending order) menggunakan algoritma gelembung (Bubble Sort)

## 2. Mathematical Equation
> Jika Ni > Ni+1, lakukan penukaran posisi (swap) sehingga Ni berpindah ke kanan.
> Jika Ni <= Ni=1, posisi data tetap dan tidak dilakukan perubahan
    Kondisi akhir yang dicapai setelah n-1 iterasi fasilasilengkap:
                  N1<=N2<=N3<=...<=Nn-1<=Nn
    Keterangan :
        - Ni = Nilai demen ke-i
        - n = jumlah total data (n=100)
        - i = indeks penyulusuran array/list (0<=i<=n)
